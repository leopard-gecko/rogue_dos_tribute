# Rogue DOS Tribute JEC.092 — macOS / Linux (English)

This document explains how to build, run, and install Rogue DOS Tribute on **macOS, Linux, and Raspberry Pi OS**, including save, score, and lock file locations. For an introduction and a list of platform-specific documents, see the [repository README](README.md). For controls and items, see [A Guide to the Dungeons of Doom](rogue_en.html).

日本語版：[README_mac_linux_ja.md](README_mac_linux_ja.md)

## 1. Requirements

Extract the source archive and open a terminal in the source directory.

**macOS:** install Apple's command-line tools:

```sh
xcode-select --install
```

**Ubuntu / Debian / Raspberry Pi OS:**

```sh
sudo apt update
sudo apt install build-essential pkg-config libncurses-dev
```

**Fedora:** `sudo dnf install gcc make pkgconf-pkg-config ncurses-devel`  
**Arch Linux:** `sudo pacman -S --needed base-devel pkgconf ncurses`  
**Alpine Linux:** `sudo apk add build-base pkgconf ncurses-dev`

The included `Makefile` normally builds the game directly with `make`. On Linux, you may first record environment-specific settings with:

```sh
./configure
```

`configure` is a small helper that detects available curses libraries and records settings in `config.mk`. It is not generated by Autoconf and does not generate `Makefile` or `config.h`. On macOS, you can also use `--with-curses-cflags` or `--with-curses-libs` if you need to adjust curses settings.

## 2. Build

For a regular build:

```sh
make clean
make
```

This produces **`rogue`**. If no previous build files exist, `make` alone is sufficient.

| Purpose | Command |
|---|---|
| Regular build | `make` |
| Name the executable `rogue-dos` | `make PROGRAM=rogue-dos` (or `make PROG=rogue-dos`) |
| Start in Japanese by default | `make japanese` |
| Start in English by default | `make english` |
| Keep regular game defaults but start in English | `make original` |
| Include wizard support | `make wizard` |

A regular `make` selects the initial language based on the OS language settings. `make original` selects English initially **without changing the gameplay rules, color, or other default options**. Both builds allow changing the language during play.

The main default settings are shown below. `on` means enabled and `off` means disabled.

| Setting | Regular `make` | `make original` |
|---|---|---|
| Startup language | Detected from the OS | English |
| `color` (color display) | on | on |
| `extchars` (extended characters) | on | on |
| `cursor` (cursor display) | off | off |

DOS-style key bindings are enabled by default. Set `nodoskeys` in the `ROGUEOPTS` environment variable at startup to select an alternative key layout. See the dungeon guide for details of the options.

With `configure`, you can specify settings such as:

```sh
./configure --program=rogue-dos
./configure --prefix=/usr --program=rogue-dos
./configure --default-language=ja
./configure --ja-man-style=mac
./configure --with-curses-libs="-lncursesw"
```

`--default-language` accepts `auto`, `ja`, or `en`. If both `PROGRAM` and `PROG` are specified, `PROGRAM` takes precedence. Compiler and build flags can be changed, for example, with `make CC=clang` or `make CFLAGS="-O2"`.

Run `make clean` before rebuilding with different build settings or file names. **Neither `make clean` nor `make distclean` removes saved games, scores, or lock files.** `make distclean` also removes `config.mk` and `config.log` in addition to build products.

## 3. Launch

From the build directory, run:

```sh
./rogue
```

A normal launch starts a new game. Use a terminal of at least **80 columns × 24 rows**.

| Command | Purpose |
|---|---|
| `./rogue -r` | Resume the game from the default save file |
| `./rogue -s` | Display the high-score list |
| `./rogue adventure.save` | Resume a named save file |

The initial display language and other options can also be set with the **`ROGUEOPTS`** environment variable:

```sh
ROGUEOPTS=language=ja ./rogue
ROGUEOPTS=language=en ./rogue
ROGUEOPTS=language=auto ./rogue
ROGUEOPTS=nodoskeys ./rogue
```

`language=auto` detects the initial language from the OS. On macOS/Linux, it checks `LC_ALL`, `LC_MESSAGES`, then `LANG`. `ROGUEOPTS` is read at startup, and settings available in the in-game options screen can be changed during play. When restoring a game, the saved `terse` and `jump` values take precedence over the startup settings.

For controls and options, consult the guide or press `?` during play.

## 4. Installation (optional)

Installation is optional if you play from the build directory. To install the executable, English/Japanese manual pages, and bundled documents under `/usr/local`, run:

```sh
sudo make install
```

To install elsewhere, use `./configure --prefix=DIR` first. Use `--program=NAME` to name the executable. The `--ja-man-style=auto|linux|mac|all|none` setting selects the Japanese manual-page locations.

For packaging or staging, you can set a temporary installation root:

```sh
make install DESTDIR=/tmp/rogue-stage prefix=/usr
```

To uninstall, run `make uninstall` with the same installation settings. `make install` does not create or install save, score, or lock files. If `FILEDIR` is specified, however, it creates the directory itself as needed.

## 5. Save, score, and lock file locations

By default, **`rogue.save`**, **`rogue.scr`**, and **`rogue.lck`** are kept in the game's working directory. Changing the executable name also changes the default data file names.

**Place all three data files in a dedicated directory:**

```sh
mkdir -p "$HOME/.local/share/rogue"
./configure --program=rogue-dos --file-dir="$HOME/.local/share/rogue"
make clean
make
```

In this example, the executable is `rogue-dos` and the data files are `rogue-dos.save`, `rogue-dos.scr`, and `rogue-dos.lck`. If running the executable directly, create the data directory first, as above, and ensure the player has write permission. If `make install` creates the directory, check its ownership and permissions.

Without `configure`, you can also specify `FILEDIR` and `PROGRAM` (or `PROG`) at build time:

```sh
make PROGRAM=rogue-dos FILEDIR="$HOME/.local/share/rogue"
```

Individual filenames can be set with `SAVEFILE`, `SCOREFILE`, and `LOCKFILE`. Explicit filenames take precedence over `FILEDIR`:

```sh
make PROGRAM=rogue-dos SAVEFILE=my.save SCOREFILE=my.scr LOCKFILE=my.lck
./configure --program=rogue-dos --save-file=my.save --score-file=my.scr --lock-file=my.lck
```

A quoted path such as `--file-dir='~/Documents'` is supported: `configure` expands the leading `~/` to the current user's home directory before saving it in `config.mk`. The same handling applies to other path options, including `--save-file`, `--score-file`, `--lock-file`, and `--prefix`. The `~username` form is not expanded.

Relative paths are resolved from the game's working directory. Rebuild after changing data paths or filenames.

## 6. Files and distribution

| File | Purpose |
|---|---|
| `rogue` | Built executable |
| `rogue.save` / `rogue.scr` / `rogue.lck` | Save / score / lock files used during play |
| `configure` / `Makefile` | Build, configuration, and installation |
| `config.mk` / `config.log` | Settings and log generated by `configure` |
| `rogue.6.en.in` / `rogue.6.ja.in` | English/Japanese manual-page templates |
| `rogue_ja.html` / `rogue_en.html` | Japanese/English HTML guides |
| `rogue_ja.txt` / `rogue_en.txt` | Japanese/English text guides |
| `README_windows_ja.md` / `README_windows_en.md` | Windows-specific READMEs |
| `*.c` / `*.h` | Source files |

Create a source archive with:

```sh
make dist.src
```

This creates `rogue_dos_tribute_jec092-src.tar.gz`, containing source files, build files, license, READMEs, guides, and manual-page templates.

To create an archive with the executable and generated manual pages, run:

```sh
make dist
```

This produces `rogue_dos_tribute_jec092.tar.gz`. For an introduction and links to the bundled documents, see the [repository README](README.md).
