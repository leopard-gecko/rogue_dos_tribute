# Rogue DOS Tribute JEC.091

This source tree builds a single executable named "rogue".
For native Windows 10/11 builds and distribution, see README_windows_en.md.
The build and install instructions below apply to macOS/Linux.

Rogue DOS Tribute is an independent derivative based on Rogue 5.4-family
source code, including the portable framework of Rogue 5.4.5 JEC. Its
monsters, items, rules, controls, and presentation have been reworked with
reference to DOS Rogue 1.48. It is not a direct port of the original
DOS Rogue 1.48 source. It adds Japanese/English switching, color, and
support for modern macOS, Linux, and Windows.

## Build

This source tree can be built directly with the checked-in Makefile.  A small
configure helper is also provided for Linux and other systems where you want to
record local settings before building.  This configure script is not generated
by Autoconf; it only writes config.mk for the Makefile to include.  It does not
generate Makefile or config.h.

On macOS, install the Xcode command line tools if a compiler is not already
available.

On Linux, install a C compiler, make, pkg-config, and the ncurses wide-character
development package.  Package names differ by distribution; common examples are:

    Debian / Ubuntu / Raspberry Pi OS: build-essential pkg-config libncurses-dev
    Fedora:                            gcc make pkg-config ncurses-devel
    Arch Linux:                        base-devel pkg-config ncurses
    Alpine Linux:                      build-base pkgconf ncurses-dev

Example commands for installing the development environment:

    macOS:
        xcode-select --install

    Debian / Ubuntu / Raspberry Pi OS:
        sudo apt update
        sudo apt install build-essential pkg-config libncurses-dev

    Fedora:
        sudo dnf install gcc make pkgconf-pkg-config ncurses-devel

    Arch Linux:
        sudo pacman -S --needed base-devel pkgconf ncurses

    Alpine Linux:
        sudo apk add build-base pkgconf ncurses-dev

Usually, build with:

    make

To use configure first, run:

    ./configure
    make

configure checks for curses/ncurses using pkg-config, ncursesw-config,
-lncursesw, -lncurses, and -lcurses, then writes the result to config.mk.
config.mk is included automatically by the Makefile.

The default build creates one executable:

    ./rogue

The default build uses convenience defaults for this bilingual/color port:

    color
    extchars
    nocursor

Local settings can be supplied on the make command line, for example:

    make CC=clang
    make CFLAGS="-O2" LDFLAGS="..." LIBS="-lncursesw"

Common configure examples are:

    ./configure --program=rogue-dos
    ./configure --prefix=/usr --program=rogue-dos
    ./configure --default-language=ja
    ./configure --ja-man-style=mac
    ./configure --with-curses-libs="-lncursesw"

To remove config.mk and config.log generated by configure, use:

    make distclean

## Distribution archives

Two distribution targets are provided.

    make dist.src

creates a source archive named rogue_dos_tribute_jec091-src.tar.gz.  This is the
archive to use when publishing the source tree.  It contains the source files,
build files, license, README files, guides, HTML guides, and manual-page
templates.

    make dist

first builds the program and manual pages, then creates a binary/documentation
archive named rogue_dos_tribute_jec091.tar.gz.  It contains the executable, license,
README files, guides, HTML guides, and generated manual pages.

## Language selection

The startup display language can be selected with the language option in
ROGUEOPTS:

    ROGUEOPTS=language=ja ./rogue
    ROGUEOPTS=language=en ./rogue
    ROGUEOPTS=language=auto ./rogue

language=ja selects Japanese, language=en selects English, and language=auto
uses the OS language setting to choose the initial language.  auto is only an
initial-language mode and is not shown on the in-game option screen.  During
play, use the "language" option and press J for Japanese or E for English.
User-entered names and call names are kept as UTF-8 strings.

At startup, ROGUEOPTS language=ja/en/auto has priority over the build-time
default.  The normal make build defaults to auto.  In auto mode, Unix-like
systems check LC_ALL, LC_MESSAGES, then LANG; Japanese locales select Japanese
and other locales select English.  Native Windows uses the user's UI language.

ROGUEOPTS is read only once at startup.  For new games, terse/noterse and
jump/nojump set the initial options.  On restore, the saved terse and jump
values take precedence.  Display language is still selected at startup and
can be changed during play.

To build a binary whose default language ignores the user's locale, use
these make targets.

    make japanese
    make english
    make original

make english keeps the standard option defaults and makes English the default
language.  make japanese keeps the standard option defaults and makes Japanese
the default language.  make original selects English initially without changing
the DOS 1.48 game rules or JEC color/option defaults.  configure accepts
--default-language=auto, ja, or en.

DOS-style key bindings are enabled by default.  Set nodoskeys in ROGUEOPTS
to use key bindings based on Rogue 5.4 instead.

    ROGUEOPTS=nodoskeys ./rogue

For details of the controls, see the guide or press ? during play.

## Program and data file names

The executable name can be changed at build time with PROGRAM.  PROG is
also accepted as a short alias, matching the other Rogue ports.  If both
PROGRAM and PROG are specified, PROGRAM takes precedence.  The default
save, score, and lock file names follow PROGRAM unless each file name is
overridden explicitly.

Examples:

    make PROGRAM=rogue-dos
    make PROG=rogue-dos

With configure, use --program:

    ./configure --program=rogue-dos

These build the executable as rogue-dos and use these play-time data files:

    rogue-dos.save
    rogue-dos.scr
    rogue-dos.lck

To place all three data files in the same directory, use FILEDIR or
--file-dir.  When FILEDIR is set, make install creates that directory
automatically.

    make PROGRAM=rogue-dos FILEDIR=$HOME/.local/share/rogue
    make PROGRAM=rogue-dos FILEDIR=$HOME/.local/share/rogue install

With configure, use:

    ./configure --program=rogue-dos --file-dir=$HOME/.local/share/rogue
    make
    make install

If you run the uninstalled binary directly from the build directory, create
the specified directory first.

These use:

    ~/.local/share/rogue/rogue-dos.save
    ~/.local/share/rogue/rogue-dos.scr
    ~/.local/share/rogue/rogue-dos.lck

The file names can also be overridden individually.  Individual file names
take precedence over FILEDIR.

    make PROGRAM=rogue-dos SAVEFILE=my.save SCOREFILE=my.scr LOCKFILE=my.lck
    ./configure --program=rogue-dos --save-file=my.save --score-file=my.scr --lock-file=my.lck

## Install

Installation is optional.  To install the executable, English/Japanese manual pages, and bundled
documentation under /usr/local, use:

    sudo make install

DESTDIR and prefix are supported for packaging or local staging, for example:

    make install DESTDIR=/tmp/rogue-stage prefix=/usr

With configure, install paths can be saved in config.mk first:

    ./configure --prefix=/usr --program=rogue-dos
    make
    make install DESTDIR=/tmp/rogue-stage

To uninstall, use the same install path settings with:

    sudo make uninstall

Plain make install installs the Japanese manual page in the Linux-style
ja/man6 directory and in the macOS-style ja_JP.UTF-8/man6 and ja.UTF-8/man6
directories.  With configure, --ja-man-style=auto selects the OS-appropriate
locations.  You can also use --ja-man-style=linux, mac, all, or none.

make install does not create or install *.scr, *.lck, or *.save files.
However, when FILEDIR is set, it creates that directory only.  The *.scr,
*.lck, and *.save files are play-time data files and are created/used by the
game according to the runtime save and score file settings.

## Main characteristics of this port

Rogue DOS Tribute retains the portable build/display framework of the
Rogue 5.4.5 JEC port, while adapting gameplay toward classic DOS Rogue 1.48:

- UTF-8 Japanese/English display support with runtime language switching
- A Makefile-based build path cleaned up for macOS and common Linux systems, with a lightweight configure helper
- Standard builds default to color, one identify-scroll type, and cursor hiding during ordinary play
- Runtime-selectable extended characters via extchars / noextchars
- DOS-style corridor and maze-passage display, with a dedicated player color on passage cells
- Potion throwing effects for monsters
- DOS-style potion list, including paralysis and thirst quenching
- A single identify scroll type, blank paper, and vorpalize weapon
- Ice monster frost bolts and slime splitting
- The wand/staff of striking, crossbow, and crossbow bolts
- Monster names, stats, flags, and level-selection tables adjusted toward DOS Rogue 1.48
- PROGRAM-based executable naming, with default save, score, and lock file names following the program name
- Japanese and English guides/manual pages updated to match this source
