# Rogue DOS Tribute — JEC.091

Rogue DOS Tribute is a derivative of Rogue based on **Rogue 5.4-family source
code** (including the Rogue 5.4.5 JEC portable framework), with game rules,
controls and presentation reworked with reference to **Epyx DOS Rogue 1.48**.
It is **not** a direct port of the original DOS Rogue 1.48 source.

日本語・英語の切り替え、カラー表示、macOS・Linux・Windowsへの対応を追加しています。
ゲームの内容や演出はDOS版Rogue 1.48を参考にしていますが、その原典ソースを
直接移植したものではありません。
