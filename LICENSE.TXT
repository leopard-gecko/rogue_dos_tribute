Rogue DOS Tribute (JEC.091) — project notes
------------------------------------------
Rogue DOS Tribute is a modified Rogue derivative based on the Rogue 5.4
family and the Rogue 5.4.5 JEC porting framework. The game rules,
controls, and presentation have been modified with reference to Epyx DOS
Rogue 1.48. This is not a direct port of the DOS 1.48 source code.

The JEC-specific changes include Japanese/English display, Unicode text
input, color, and modern macOS/Linux/Windows support. These changes do
not replace or alter the copyright and license notices above.

Windows icon
------------
The Windows Explorer icon (windows/rogue.ico and windows/rogue-icon.rc)
was supplied for this project. It is separate from the original Rogue
source code; this notice does not assert that any third-party artwork is
public domain or change the rights and notices above.
